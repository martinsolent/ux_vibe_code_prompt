What "vibe coding" means here

Describing what you want, judging what comes back, and steering with feedback — like briefing a developer. Claude writes the HTML; you own the UX decisions.

What you'll produce

One self-contained .html prototype that someone can click through, plus the prompt you used and a short plain-English description of it.

The golden rule

Build only what the main task needs. A prototype is a sketch you can click, not a finished product.

Before you start

Working on the free Claude plan

The free plan includes Artifacts — the live preview panel where your prototype appears — and you can publish an artifact as a shareable link. The catch is usage: free accounts get a usage budget that refills over a rolling window of a few hours, and big files and long chats use it up fastest. Anthropic doesn't publish a fixed message count, so plan as if every message matters.

✅ Setup checklist

💡 Make your budget last

  • Think first, prompt second. Use the prompt builder so your first message is complete.
  • One change per message — but batch related tweaks ("fix these three labels").
  • Start a fresh chat when a conversation gets long; paste a summary (see the "Handover" prompt).
  • Download every working version before asking for changes — you can always go back.
  • Hit the limit? Use the wait to click through what you have, or to plan your next prompts on paper.

Privacy: never paste real personal data, names or private information into Claude. Use invented content for the prototype.

    When it goes wrong

    Troubleshooting

    The preview looks plain or unstyled

    Claude's preview can block some external files. Download the HTML and open it in Chrome or Edge — if it looks right there, the prototype is fine. Or ask Claude: "Load the design system from cdnjs.cloudflare.com if it's available there."

    Claude rebuilt everything when I asked for one change

    Say what must not change: "Change only the button text on the Confirm screen. Keep everything else exactly as it is." If it still drifts, go back to your last downloaded version.

    A button does nothing

    Describe the symptom, not the fix: what you clicked, what you expected, what happened. Then ask Claude to fix only that.

    I've hit my usage limit

    Download what you have, click through it, and plan your next 2–3 prompts. When your allowance refills, start a fresh chat with the latest HTML attached and a short summary, so you don't resend the whole history.

    Pro has a 5-hour session limit and a weekly cap. Download what you have and click through it. Next time, start a fresh chat in your Project and attach the latest HTML, rather than continuing a long chat.

    The response stopped half-way

    Reply "Continue from exactly where you stopped." For big prototypes, ask for fewer screens and build one flow at a time.

    It doesn't look like the design system

    Ask Claude to replace any custom-styled parts with the design system's own components, then compare against the system's component pages. You're the quality check.
